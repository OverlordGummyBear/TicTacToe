# Tic Tac Toe
A simple Tic Tac Toe game built with vanilla HTML, CSS, and JavaScript, using the module/factory pattern to separate game logic from the DOM.

## Features
- Two-player game with custom player names
- Score tracking across rounds
- Win and tie detection
- New Round and Reset Game controls

## Getting Started
Clone the repo and open `index.html` in your browser.
```bash
git clone https://github.com/OverlordGummyBear/TicTacToe.git
cd TicTacToe
```
Then just open `index.html` directly in the browser.
